# So arbeitet StatAgent

- **Die KI schreibt Code.** Sie bekommt keine Einzeldaten zu sehen.
- **Das Programm rechnet.** Zwei Läufe mit denselben Daten geben dieselben Zahlen.
- **Der Mensch gibt frei.** Jede Regel und jede Lieferung trägt einen Namen und einen Zeitpunkt.

<!-- notizen -->

Drei Sätze, drei Aufgaben.
Die KI schreibt nur Code und sieht keine Einzeldaten. Das Programm rechnet, ganz ohne Sprachmodell, deshalb sind die Zahlen jedes Mal gleich.
Und freigeben kann nur ein Mensch, mit Vor- und Nachnamen.
