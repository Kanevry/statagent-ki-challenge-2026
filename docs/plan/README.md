# Planstände aus der KI Challenge

Dieser Ordner hält Pläne und Messprotokolle so fest, wie sie während der Challenge entstanden sind. Sie sind
nicht nachgezogen und können überholt sein.

Der gültige Stand steht im [README](../../README.md) und unter [docs/einstieg/](../einstieg/README.md).

Die Dateien bleiben im Repo, weil die Abgabe, Kommentare im Code und Prüfungen der Abnahme auf sie verweisen.
