# Abnahme UC4 „Gemeinsamer Einstieg“ (Epic #95): Plan und Messung

Prüfer: Abnahme-Lane (Session b-abnahme-57). Stand: main `f1bf42bb47ccf60d434d690f559c521e8db847ec`.
Vertrag: `antwort(frage, kontext) -> {text, belege[], zahlen[], uc, modell, protokoll_id}`
(`shared/py/plattform/antwortform.py`, Router `shared/py/plattform/router.py`).

## Was die Jury sehen muss

Eine Frage, drei Antworten in Kettenreihenfolge (UC3, dann UC2, dann UC1). Jede Zahl stimmt mit der Datenbank, jede
Zahl hat einen Beleg, den man nachrechnen kann, und der Bürger versteht die letzte Antwort ohne Fachwissen.

## Abnahmekriterien (Vorschlag der Abnahme-Lane)

| Nr | Kriterium | Orakel | Bestanden wenn |
|---|---|---|---|
| U4-1 | Vertrag: jede Antwort ist eine gültige `UcAntwort` | Router validiert streng (`extra="forbid"`, Index-Prüfung `zahlen[i].beleg`) | 0 Validierungsfehler über alle Fragen |
| U4-2 | UC3-Zahl stimmt | eigene Abfrage auf `stat.stat_beschaeftigte` (Summe der Kreuzgliederung, `tests/abnahme/95_kette.py`) und das SQL aus dem Beleg, von der Abnahme erneut ausgeführt | Zahl = eigene Abfrage = Beleg-SQL |
| U4-3 | UC3-Beleg zeigt auf den Lauf | `meta.lauf.ergebnis_hash` des Monats | `beleg.lauf` gleich, `beleg.stand` gesetzt, bei 2025-10 `vorlaeufig` |
| U4-4 | Weitergabe ohne Verfälschung | UC2- und UC1-Antwort | Eine von UC3 übernommene Zahl trägt weiter `beleg.uc = "uc3"` und denselben `lauf` |
| U4-5 | Ohne Monat keine Zahl | Frage ohne Monat („Wie geht es den Wartezeiten?“), Monat ohne Lauf („Juli 2027“) | gültige Antwort, `zahlen = []`, kein erfundener Wert |
| U4-6 | Protokoll ohne Inhalt | `router.jsonl` | je Schritt eine Zeile, kein Fragetext |
| U4-7 | Sprache | UC1-Antwort, gelesen als Bürger | keine Fachwörter ohne Erklärung, keine Diagnose, Quelle sichtbar |
| U4-8 | Seite `/uc4` | Screens, `measureSlop` | 0 Schablonen-Treffer, Karten in Kettenreihenfolge mit Herkunft-Chip und Modell-Badge |
| U4-9 | Drehbuch „Wartezeiten“ | Lead + Review-Bank 57 | erwartete Belege, UC2-Position und UC1-Text wie im Drehbuch |
