### 4. Warum mistral nicht antwortet


```json
{"schluessel_vorhanden": true, "models_status": 200, "models_anzahl": 55, "small_latest_da": true,
```

Der Schlüssel gilt (die Modellliste kommt mit HTTP 200). Das Konto erlaubt aber **0 Anfragen pro Minute**.

`RateLimitError` wird als `ProviderFehler` gemeldet, im Standardweg fällt der Zweck auf die nächste Stufe.
Dieselbe Antwort kam schon um 13:22 (Kommentar im Issue), sie hält also seit Stunden an.
